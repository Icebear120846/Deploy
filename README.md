## ดาวน์โหลดและเปิดในเครื่อง

```bash
git clone https://github.com/Icebear120846/Deploy.git
cd Deploy
npm install
npm run dev
```

## คำสั่งที่ใช้

- `npm run dev` เปิดเว็บระหว่างพัฒนา
- `npm run build` สร้างไฟล์สำหรับเผยแพร่
- `npm run preview` ทดลองไฟล์ที่ build แล้ว
- `npm run deploy` เผยแพร่ขึ้น GitHub Pages
